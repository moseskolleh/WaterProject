Settings About & method Field tools VES co-pilot A Schlumberger sounding checked at the peg, reading
by reading, while the crew can still re-measure. It writes the standard VES workbook, which the
Geophysics page reads. The VES co-pilot, which checks each reading at the peg while the crew can
still re-measure, is in the browser app only. The Streamlit app reads the workbook it writes like
any other VES template. Before the survey Enter the depth the sounding has to see. A Schlumberger
sounding resolves to about 0.5 of its largest AB/2 (the rule the interpretation uses), so the line
is set long enough before any cable is unrolled. Target depth (m) Sounding number Propose the
spacings AB/2 and MN (m), one pair a line; an AB/2 written twice is an MN change Edit the plan to
suit the ground; the checks follow it. Use this plan At the peg AB/2 (m) MN (m), full spacing
Potential V (mV) Current I (mA) Or, where the instrument shows it, the apparent resistivity itself:
Apparent resistivity (ohm-m) Add the reading Instrument Smallest potential it reads reliably (mV)
Default 1 mV: below about a millivolt, self-potential drift and telluric noise are a large part of a
single reading. Set it from the instrument manual. Instrument Sounding curve The curve starts with
the first reading. Preview inversion A preview, not the survey's result: a fit of the readings so
far, run again after each reading, so the team can see whether basement is in view while the line
can still be extended. The Geophysics page interprets the finished workbook. The preview starts at 8
readings (0 so far). Readings No. AB/2 (m) MN (m) V (mV) I (mA) ohm-m At the peg Re-measure or
